# ASSUMPTIONS

- Среда сборки без сети: `three`, `vite`, `vitest` недоступны. Этапы А–Б (архитектура, core, солвер, генератор, mock SDK, сохранения, кулдаун, экономика) сделаны без них и проверены 27 тестами на `node:test` (`npm test`). На машине с сетью можно перейти на Vitest — API тестов тривиально совместим.
- Вместимость бутылки по умолчанию 4; у `Bottle` поле `cap` своё — разные вместимости поддерживаются ядром уже сейчас.
- Генерация уровня: случайная раскладка → обязательная проверка солвером (A* с допустимой эвристикой «блоки − цвета», вес 1 для par, вес 3 для быстрой проверки). Seed детерминирован: `seed#попытка`.
- Звёзды: 3★ ≤ 1.15·par, 2★ ≤ 1.6·par (config/balance.ts). Par — оптимум солвера (или лучшее найденное при лимите узлов).
- Свободная игра: число бутылок = цвета + пустые, шаг роста — каждые 5 уровней; цветов не больше 12, при 13+ бутылках добавляются пустые.
- Главы 2–4 — шаблоны (`content/chapters.ts`), механики (`hiddenLayers`, `mixedCapacity`, `sealed`) пока только объявлены.
- Кулдаун рекламы: эффективное время = max(последнее известное + монотонный прирост, серверное/системное). Откат часов не сокращает ожидание; цена — при откате часов между запусками игрок ждёт, пока часы «догонят».
- Язык: ru/be/kk/uk/uz → русский, остальное → английский.
