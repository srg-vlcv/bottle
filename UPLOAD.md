# Как загрузить игру в консоль Яндекс Игр

1. **Подготовка (один раз):** установите Node.js 20+, в папке проекта `npm install`.
2. **Сборка архива:** `npm run package` (если меняли уровни глав — сначала `npm run bake`).
   Скрипт сам прогоняет типы и тесты, собирает проект, проверяет размер и создаёт `dist.zip` (index.html в корне архива).
   Если что-то падает — исправьте и запустите снова: битый архив не создаётся.
3. **Черновик игры** в консоли разработчика: создайте игру, тип — HTML5, загрузите `dist.zip`.
4. **Настройки в консоли:** ориентация — любая (игра сама подстраивается под телефон и ПК), языки RU и EN, возрастной рейтинг.
5. **Платежи:** заведите товары из `PAYMENTS.md` (расходуемые; id в точности как в таблице). Включите платежи для игры.
6. **Рейтинг:** создайте лидерборд с именем `stars` (сортировка по убыванию).
7. **Проверка на черновике:** откройте игру по ссылке черновика и пройдите матрицу из `MODERATION.md`.
   Добавьте к адресу `?debug=1`, чтобы видеть FPS и счётчики памяти.
8. **Карточка игры:** иконка, обложка, скриншоты, описание на двух языках.
9. **Отправьте на модерацию.** После публикации смотрите статистику в консоли: удержание, сессии, доход от рекламы и платежей.

## Аналитика по уровням
Игра копит события локально (где бросают уровень, где застревают). В консоли браузера: `bottlesDebug.stats()` (только с `?debug=1`).
Чтобы события уходили в Метрику, впишите номер счётчика в `src/config/analytics.ts` — но уточните в правилах площадки, разрешён ли
сторонний счётчик внутри игры. По умолчанию выключено.

## Быстрые настройки баланса
Все числа — в `src/config/`: `balance.ts` (бонусы, реклама, награды), `shop.ts` (сундуки, товары), `daily.ts`, `events.ts`.
