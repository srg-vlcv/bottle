# Бутылочки — Water Sort для Яндекс Игр

## Запуск
```bash
npm install
npm run dev        # http://localhost:5173 (локально работает MockSdk)
npm test           # юнит-тесты ядра (node:test через tsx)
npm run check:shaders   # компиляция всех GLSL-шейдеров в headless Chromium (нужен playwright)
npm run package         # типы + тесты + сборка + проверка размера + dist.zip для консоли Яндекса
npm run build && npm run check:size   # сборка в dist/, проверка размера (<100 МБ)
```
На Яндекс Играх загружайте содержимое `dist/` (zip с index.html в корне). Тег `/sdk.js` подставляет платформа.

## Структура
- `src/core` — чистая логика: правила, undo, победа, солвер (A*), генератор, кулдаун, экономика, сохранения.
- `src/render` — three.js: бутылки (Lathe), шейдер жидкости и стекла, струя, частицы, сцена и анимация переливания.
- `src/ui` — DOM-HUD поверх canvas (кнопки под большой палец, safe-area). `src/services` — SDK(+mock), сохранения, i18n.
- `src/config/balance.ts` — весь баланс. `src/content` — главы и темы.

## Как добавить
- **Главу:** запись в `CHAPTERS` (`content/chapters.ts`), `implemented: true` когда готова.
- **Тему:** файл по образцу `content/themes/lab.ts`.
- **Язык:** ключи в `services/i18n.ts`. **Бонус:** `config/balance.ts` + `BonusId` + кнопка в `ui/hud.ts`.

## Платежи и магазин
Список товаров для консоли Яндекса и порядок начисления — `PAYMENTS.md`. Баланс сундуков и товаров — `src/config/shop.ts`.

## Превью стекла
`npm run preview:glass` рисует бутылки тем же профилем и шейдерами на чистом WebGL2 (нужен playwright) — удобно подбирать вид стекла.

## Картинки
См. `ASSETS.md` — куда класть портреты персонажей и фон.

## Экраны (этап Г)
Главное меню (на фоне живая сцена) → Сюжет (главы и уровни со звёздами) / Свободная игра (4 сложности по числу бутылок) → игра с паузой → окно победы.
Настройки: язык, звук, музыка, режим для дальтоников (узоры на слоях). Генерация уровней и подсказки/проверка тупика идут в Web Worker.

## Темы, награды, события (этап Ж)
- **Темы:** по одному файлу в `src/content/themes/` + строка в `index.ts`. Палитра проверяется тестом (12 цветов, попарно различимы).
- **Ежедневная награда:** `src/config/daily.ts` (цикл 7 дней, 1 день пропуска «прощается»).
- **Событие дня:** `src/config/events.ts` — шансы наград и пороги сложности. Награда одинакова у всех игроков в этот день.
- **Достижения:** `src/core/achievements.ts` (20 штук, награда выдаётся автоматически).
- **Рейтинг:** в консоли Яндекса создайте лидерборд с именем `stars` (сортировка по убыванию, тип «число»). Очки пишутся только авторизованным игрокам.

## Загрузка и модерация
`UPLOAD.md` — пошаговая загрузка в консоль, `MODERATION.md` — чек-лист и матрица ручной проверки, `PAYMENTS.md` — товары.
Отладка: добавьте `?debug=1` к адресу — в углу FPS и счётчики рендера (для поиска утечек).

## Механики и главы (этап И)
- **Глава 2** — слои «?» (открываются, когда становятся верхними), **Глава 3** — бутылки разной вместимости, **Глава 4** — запечатанные бутылки (+ «?»).
  Главы открываются по порядку; за главу — 💎 и сундук (серебряный, с 3-й главы золотой).
- Правила — `src/core/rules.ts` (`hidden`, `locked/lockedBy`, `cap`), уровни — `src/content/chapters.ts`.
- **Запечённые уровни:** сюжетные уровни считаются заранее (`npm run bake` → `src/content/baked.ts`), поэтому игрок не ждёт генерации.
  Меняли уровни глав или генератор — запустите `npm run bake`; тест `npm test` подскажет, если запечённые данные устарели.
